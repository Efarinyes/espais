# UI/UX mobile — Espais

## Principis

360–430px primer. Paleta neutra única. Glossari català. CTA clara als buits. Anul·lar = confirmació + text que s’avisa el coordinador.

## Checklist

- [ ] Toc ≥ 44px, focus visible, labels
- [ ] Contrast AA
- [ ] Empty states de [14-ui-ux.md](../../../docs/14-ui-ux.md)
- [ ] Errors al camp, no només toast
- [ ] Accions destructives amb text, no només icona
- [ ] Quan hi hagi app: recórrer el flux, no només screenshot

## Fluxos a verificar (quan existeixin)

Registre → primer espai → reserva → anul·lació pel responsable → avís al coordinador.
